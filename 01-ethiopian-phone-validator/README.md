# Ethiopian Phone Number Validator 🇪🇹

A small JavaScript web application that checks whether an Ethiopian mobile phone number follows a valid format.

## Features

* Validates Ethiopian mobile numbers
* Supports local format: `09XXXXXXXX`
* Supports international format: `+2519XXXXXXXX`
* Supports `2519XXXXXXXX`
* Removes spaces automatically
* Shows the detected phone number format
* Character counter
* Example number buttons
* Clear button
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* Regular Expressions

## Valid Examples

```text
0912345678
+251912345678
251912345678
```

## Invalid Examples

```text
0812345678
091234567
1234567890
+251812345678
```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter an Ethiopian phone number.
5. Click **Check Number**.
