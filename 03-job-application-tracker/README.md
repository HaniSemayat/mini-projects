# 💼 Job Application Tracker

A simple, responsive job application tracker built with **HTML, CSS, and vanilla JavaScript**.

This project helps users keep track of job and internship applications, including their company, position, location, application date, status, application link, and notes.

## ✨ Features

* Add new job applications
* Edit existing applications
* Delete applications
* Search applications by company or position
* Filter applications by status
* Sort applications by:

  * Newest first
  * Oldest first
  * Company A–Z
  * Company Z–A
* Dashboard statistics
* Form validation
* Persistent data using `localStorage`
* Responsive design for desktop and mobile
* Empty state when no applications match the current filters

## 🚀 How to Run

No installation or build tools are required.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Or use VS Code with **Live Server** for a better development experience.

## 💾 Data Persistence

The application uses the browser's `localStorage` to save application data.

This means applications remain available after refreshing or reopening the page in the same browser.

No backend or database is required.
