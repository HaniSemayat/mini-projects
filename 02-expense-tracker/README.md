# Mini Expense Tracker 💰

A simple expense tracker built with HTML, CSS, and JavaScript.

## Features

* Add and delete expenses
* Track total spending
* Categorize expenses
* Filter by category
* Select expense dates
* Save expenses using localStorage
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* localStorage

## What I Practiced

* DOM manipulation
* Arrays and objects
* Array methods
* Event listeners
* Forms and validation
* localStorage
* Date handling
